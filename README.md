# ai-book Physical AI Book

This repository contains the Physical AI Book, a Docusaurus-based educational resource for learning about Physical AI concepts. The book provides an accessible introduction to this field with interactive elements.

## About the Physical AI Book

The Physical AI Book is designed to provide an accessible introduction to Physical AI concepts. It uses the Docusaurus framework to create a rich, interactive learning experience with documentation, examples, and exercises.

## Getting Started

### Prerequisites

- Node.js version 18 or higher
- npm or yarn package manager

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd ai-book
   ```

2. Install frontend dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

This command starts a local development server. The Docusaurus site will open in your default browser at `http://localhost:3000`.

### Building for Production

To build the static site for deployment:

```bash
npm run build
```

This creates a `build/` directory with the complete static site that can be deployed to any web server.

## Deploying to GitHub Pages
